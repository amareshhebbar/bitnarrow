Chat with a bitnarrow artifact and compare it side by side with its base model.

Set these Space variables:

* `BITNARROW_REPO`: the artifact repo, for example `AmareshHebbar/Qwen2.5-1.5B-Narrow`
* `BITNARROW_BASE`: optional base model id to enable the comparison tab, for example `Qwen/Qwen2.5-1.5B-Instruct`
